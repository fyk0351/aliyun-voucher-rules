## 领到的券怎么用？预付费和按量付费是两套流程

买包年包月资源（比如包年的ECS）时，确认订单页面会自动筛选出可用的优惠券，你手动选一张抵扣。几条规则记牢：

- 单笔订单只能用一张券；一张券在有效期内可以抵扣多个订单，直到余额用完。
- 有多张券可用时，系统默认先抵扣余额最大的；余额相同，先用到期时间早的。
- 券的面额不够付订单，差价从现金账户补；用完还有剩，余额留在券里，下次接着用。
- 在确认订单页面选了券之后，这张券会被未支付订单冻结，得先把那笔未支付订单作废，券才会恢复可用状态。

按量付费不用手动操作。系统出账时自动用生效中的券抵扣，优先用快过期的；单张余额不够，会自动接续下一张代金券，直到账单抵完或券用尽。但欠费部分不能用券抵，需要自己充值还清，补齐之后再产生的按量费用才能继续用券。

支付环节还有个细节：券是需要手动勾选确认的，付款前多看一眼支付页有没有带上你要用的那张，别想当然以为它会自动生效。

## 这些产品用不了通用代金券，下单前对照一下

很多人看到券上写“全部商品适用”就默认真的全都行，实际排除名单里有一些日常会买的产品。

常用的排除项包括：域名、商标服务、CDN、短信服务、语音服务、号码隐私保护等云通信类产品、云数据库OceanBase版、云市场三方商品，以及服务器硬件这类实物商品。另外从2023年6月8日起，标注“全部商品适用”的优惠券不再支持抵扣短信服务、语音服务和轻量消息队列（MNS）的消费——习惯用短信服务的项目要特别注意这一条。

指定商品券不受这份名单影响，但只限于活动规定的商品。拿不准的时候，去优惠券管理页面看那张券的“适用商品”和“订单类型”，比猜测可靠得多。

## 退款和发票规则，领券之前就该知道

这是全文最值得提前看的一节。代金券的使用是不可逆的：即使订单符合“5天无理由退款”，退款时也只退实际支付的现金部分，代金券抵扣的那部分不予退还，也不会补发新券。举个官方说明里的例子：用代金券买一台支持5天无理由退款的ECS实例，之后申请退款，券抵掉的钱就没了。

发票同理。代金券抵扣的金额属于虚拟权益，开不了发票，只有实际付现金的部分能申请发票。企业采购走报销流程的话，做预算时要把这一层算进去。

有些场景券会退回：支付前取消已选券的订单，券直接退回；资源开通失败、账单回滚修正，代金券和满减券支持退回（折扣券不行）。但域名、云虚拟主机这类产品在下单或资源创建失败后，券不退。

## 常见问题

**代金券能用来续费吗？**

可以。条件是券在有效期内，且适用场景包含“续费”或者本身是通用券。手动续费时，确认订单页面会展示适用的优惠券；开通自动续费的话，系统会按适用规则自动选择抵扣。

**手机端领的券，电脑上看不到怎么办？**

先确认两端登录的是同一个阿里云主账号，可以通过手机号或实名认证信息找回。确认是同一账号还看不到，检查该券是否与当前享受的活动互斥，或者有没有特殊使用门槛。

**下单时没看到可用的优惠券？**

常见原因有这几种：券不适用于当前购买的产品、已过期、订单类型不在适用范围、满减券没达到金额门槛、已经享受了其他折扣或活动互斥、订单时长不满足条件。逐项对照券详情基本能定位问题，个别情况换个浏览器或改用电脑端就能解决。

**领取数量有上限吗？**

单个账号最多同时持有50张有效券。另外活动红包类代金券有效期通常不长，活动规则里写过“领取后30天内有效”，具体以每张券在控制台显示的失效时间为准，领了尽快用。
